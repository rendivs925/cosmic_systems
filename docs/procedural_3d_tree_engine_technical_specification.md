# Technical Specification: Photorealistic Procedural 3D Tree Engine

## 1. Executive Summary & Objective

This document provides a complete technical specification and algorithmic framework for building a high-performance, photorealistic procedural 3D tree generator in **Three.js / WebGL** (or native game engines like Unreal/Unity/Houdini). 

The goal is to eliminate common visual artifacts found in naive procedural implementations—such as disconnected trunk cylinders, visible gaps between branch joints, sparse "cardboard cutout" leaves, flat shading, and unnatural branch angles—and replace them with a unified, botanically accurate generation engine.

---

## 2. Core Architectural Principles

| Feature Area | Naive / Flawed Approach | Photorealistic Procedural Standard |
| :--- | :--- | :--- |
| **Branch Mesh** | Disjointed `THREE.CylinderGeometry` objects stacked end-to-end (causes gaps). | Continuous single-pass `BufferGeometry` extrusion generated by lofting ring cross-sections along interpolated space curves. |
| **Branch Tapering** | Uniform or random radii. | Strict adherence to **Leonardo da Vinci's Pipe Model Law** ($r_{\text{parent}}^k = \sum r_{\text{child}}^k$). |
| **Canopy Volume** | Random leaf quad planes placed at branch ends. | Hierarchical cluster lobes with multi-planar sprig cards and volumetric normal transfers. |
| **Foliage Shading** | Default Phong/Standard mesh lighting (leaves look like plastic or cardboard). | Custom GLSL shader with **Volumetric Normal Bending**, **Subsurface Scattering (Translucency)**, and **GPU Wind Animation**. |
| **Branch Transitions** | Hard sharp breaks at splits. | Smooth radius blending and curved branch collar transitions. |

## 3. Procedural Branching & Trunk Engine

### 3.1 Leonardo da Vinci's Area Preservation Rule
To ensure natural branch tapering from the trunk base to terminal twigs, the cross-sectional area of the parent branch must equal the sum of the cross-sectional areas of its child branches:

$$r_{\text{parent}}^k = \sum_{i=1}^{N} r_{\text{child}, i}^k$$

- **Exponents ($k$):** $1.8 \le k \le 2.3$ (typically $k = 2.0$ for ideal volume preservation).
- **Radius Equation for $N$ identical children:** 
  $$r_{\text{child}} = r_{\text{parent}} \cdot N^{-1/k}$$

### 3.2 Continuous Extrusion & Seamless Vertex Generation
Instead of instantiating separate cylinder meshes, construct a single merged `BufferGeometry` via recursive ring sampling:

1. **Space Curve Formulation:** Define each branch segment as a continuous curve $P(t)$ where $t \in [0, 1]$.
2. **Noise & Tropism Vectors:** Add displacement vectors along $P(t)$:
   $$\vec{P}(t) = \vec{P}_{\text{start}} + t \cdot L \cdot \vec{D} + \text{Noise}(t) \cdot \vec{N} - \text{Gravity}(t^2) \cdot \hat{k}$$
   - **Phototropism:** Upward vector drift towards sunlight.
   - **Gravitropism/Sag:** Downward bending due to gravity ($\text{Sag} \propto L \cdot \text{mass}$).
   - **Gnarliness:** Multi-octave Perlin/Simplex noise perturbing branch trajectories.
3. **Frenet-Serret / Orthogonal Frames:** Compute parallel transport frames along $P(t)$ with Tangent $\vec{T}$, Normal $\vec{N}$, and Binormal $\vec{B}$ vectors to avoid twisting ring geometry.
4. **Ring Vertex Generation:** For radial segment $r \in [0, S_{\text{radial}}]$ and step $s \in [0, S_{\text{height}}]$:
   $$\vec{V}(r, s) = P(s) + R(s) \cdot \left( \cos\theta \cdot \vec{N} + \sin\theta \cdot \vec{B} \right)$$
   Where $\theta = \frac{2\pi r}{S_{\text{radial}}}$ and $R(s)$ is the interpolated radius.
5. **Buttress Roots & Flare:** At the base ($Z \approx 0$), inflate $R(s)$ using an exponential flare modifier:
   $$R_{\text{base}}(z) = R_0 \cdot \left( 1.0 + A_{\text{flare}} \cdot e^{-c \cdot z} \right) \cdot \left( 1.0 + 0.3 \cdot \sin(K_{\text{roots}} \cdot \theta) \right)$$

## 4. Volumetric Canopy & Foliage System

### 4.1 Hierarchical Cluster Lobes
Single leaf quads create thin, unrealistic trees. Leaves must be organized into **Volumetric Branch Sprigs**:
1. **Terminal Node Identification:** Identify terminal twigs where recursion depth reaches maximum iteration ($d = D_{\text{max}}$).
2. **Cluster Centroid Allocation:** Define spherical/ellipsoidal bounding volumes around terminal branch groups.
3. **Instanced Multi-Planar Sprigs:** Instance 3D leaf cards containing 3 intersecting planes (cross-star format) or textured foliage sprays within each cluster volume.

### 4.2 Volumetric Spherical Normal Transfer (Crucial for Realism)
Default flat geometry normals cause individual leaf planes to highlight unnaturally under direct light. To fix this, replace individual vertex normals with vectors radiating outward from the canopy cluster center:

$$\vec{N}_{\text{final}} = \text{normalize}\left( (1 - \alpha) \cdot \vec{N}_{\text{mesh}} + \alpha \cdot \text{normalize}(\vec{P}_{\text{world}} - \vec{C}_{\text{cluster}}) \right)$$

- **$\vec{C}_{\text{cluster}}$:** The center position of the foliage cloud lobe.
- **$\alpha$:** Blending weight ($0.6$ to $0.85$ works best).
- **Result:** The entire leaf canopy behaves like a smooth, volumetric mass (shading gracefully with deep shadows in interior pockets and bright highlights on exterior lobes).

## 5. Shaders & Material Pipeline

### 5.1 Subsurface Scattering (SSS) / Translucency Shader
Leaves are thin translucent membranes. When light hits the back of a leaf, it must illuminate the front.

**GLSL Fragment Shader Snippet:**
```glsl
// Uniforms
uniform vec3 uSunDirection;
uniform vec3 uLeafColor;
uniform vec3 uSubsurfaceColor;
uniform float uTranslucency;

varying vec3 vNormal;
varying vec3 vWorldPosition;

void main() {
    vec3 lightDir = normalize(uSunDirection);
    vec3 normal = normalize(vNormal);

    // Front-face Lambertian light
    float NdotL = max(dot(normal, lightDir), 0.0);

    // Back-lit Translucency (Subsurface Scattering approximation)
    float backLight = max(dot(-normal, lightDir), 0.0);
    vec3 subsurface = pow(backLight, 2.0) * uSubsurfaceColor * uTranslucency;

    vec3 finalColor = uLeafColor * (NdotL + 0.2) + subsurface;
    gl_FragColor = vec4(finalColor, 1.0);
}
```

### 5.2 GPU Vertex Shader Wind Sway
Do not update leaf positions on the CPU. Move wind calculations directly into the GPU vertex shader:

```glsl
uniform float uTime;
uniform float uWindStrength;
attribute vec3 aClusterCenter;

void main() {
    vec3 pos = position;
    
    // Wind wave calculation based on height and world position
    float wave = sin(uTime * 2.0 + aClusterCenter.x * 0.5 + aClusterCenter.y * 0.3);
    vec3 windDisplacement = vec3(
        wave * uWindStrength * 0.15,
        cos(wave * 0.8) * uWindStrength * 0.05,
        cos(wave * 1.2) * uWindStrength * 0.10
    );

    // Scale wind displacement by height above ground
    float heightFactor = clamp(position.y / 15.0, 0.0, 1.0);
    pos += windDisplacement * heightFactor;

    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
}
```

### 5.3 Alpha-Tested Shadow Maps
Assign a `customDepthMaterial` to the instanced foliage mesh using `alphaTest: 0.5` so that light casts intricate leaf-patterned shadows onto the trunk and ground plane rather than solid square shadows.

## 6. Procedural Bark & Foliage Texture Generation

### 6.1 Procedural Bark Shader / Canvas Generator
Generate dynamic PBR textures via Canvas API or GLSL noise:
- **Base Color:** Deep organic brownish-grey (`#2B1E16`).
- **Vertical Furrows:** Non-uniform directional Perlin noise stretched along the $V$-axis ($2 \times 8$ UV tiling).
- **Knots & Rings:** Ring perturbation noise for irregular bark knots.
- **Normal Map:** Heightmap converted to Normal map via Sobel filter to create physical bark grooves.

### 6.2 High-Resolution Foliage Sprig Canvas
Create 512x512 procedural canvas textures for leaf sprigs:
- Draw central dark brown stems.
- Render multi-layered leaf shapes with color variation (deep emerald green, bright lime tips, autumn amber).
- Add leaf veins using faint semi-transparent strokes.
