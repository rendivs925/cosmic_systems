## **2\. Atmospheric Scattering (Bruneton Model & Volumetric Fog)**

Atmospheric scattering models single and multiple scattering using Bruneton’s precomputed Rayleigh and Mie scattering framework extended with dynamic volumetric fog density fields.

### **2.1 Precomputed Scattering Equations**

The total light reaching a viewer at position $x$ from direction $v$ at distance $d$ is given by:

$$L(x,v)={L}_{0}(x+dv)\cdot T(x,x+dv)+S(x,v,d)$$

Where:

> * $T(a,b)=\exp \left({-\int\limits_{a}^{b}({\beta }_{R}(h(s))+{\beta }_{M}(h(s))+{\beta }_{{O}_{3}}(h(s)))ds}\right)$ is the **Transmittance** between points $a$ and $b$.  
> * ${\beta }_{R}(h)={\beta }_{R}^{0}{e}^{-h/{H}_{R}}$ is the Rayleigh scattering coefficient (${H}_{R}=8.0km$).  
> * ${\beta }_{M}(h)={\beta }_{M}^{0}{e}^{-h/{H}_{M}}$ is the Mie scattering/absorption coefficient (${H}_{M}=1.2km$).  
> * ${\beta }_{{O}_{3}}(h)$ represents ozone absorption concentrated in a mid-atmosphere layer ($15-25km$).

#### **Phase Functions**

> **Rayleigh Phase Function** (Symmetrical scattering):

> $${P}_{R}(\theta )=\frac{3}{16\pi }(1+{\cos }^{2}\theta )$$

> **Cornette-Shanks Phase Function** (Mie scattering approximation for aerosols):

> $${P}_{M}(\theta ,g)=\frac{3(1-{g}^{2})}{8\pi (2+{g}^{2})}\frac{1+{\cos }^{2}\theta }{(1+{g}^{2}-2g\cos \theta {)}^{3/2}}$$

### **2.2 Volumetric Fog & Analytical Height-Based Density**

Local atmospheric density $\rho (y)$ varies with height $y$ and perlin-noise modulated analytical parameters:

$$\rho (y)={\rho }_{0}\cdot \exp \left({-\frac{y-{y}_{0}}{{H}_{fog}}}\right)\cdot \max\limits_{}\left({0.0,1.0+\eta (x\cdot f)}\right)$$

In-scattered lighting inside the volumetric fog frustum volume buffer (Voxel Grid $160\times 90\times 128$) is ray-marched on the GPU using a temporal jittered offset to reduce slicing artifacts.

## **3\. Water Rendering & Surface Physics**

Water surfaces are synthesized physically through **Fast Fourier Transform (FFT) statistical wave spectra (JONSWAP / Tessendorf)** and rendered using adaptive screen-space or projected grid geometry.

### **3.1 Tessendorf / JONSWAP Wave Spectrum Equations**

The surface height displacement vector $h(x,t)=(x+{\xi }_{x},\ y+\eta ,\ z+{\xi }_{z})$ at world space location $x=(x,z)$ and time $t$ is expressed as a sum of spatial wave components:

$$h(x,t)=\sum\limits_{k}^{}\tilde{h}(k,t){e}^{ik\cdot x}$$

The spatial spectrum at time $t$ is generated via complex initial noise coefficients ${\tilde{h}}_{0}(k)$:

$$\tilde{h}(k,t)={\tilde{h}}_{0}(k){e}^{i\omega (k)t}+{\tilde{h}}_{0}^{*}(-k){e}^{-i\omega (k)t}$$

Where:

> * $\omega (k)=\sqrt{g\parallel k\parallel \left({1+\parallel k\parallel {}^{2}\frac{\sigma }{\rho }}\right)}$ is the dispersion relation including gravity $g$ and surface tension $\sigma$.  
> * ${\tilde{h}}_{0}(k)=\frac{1}{\sqrt{2}}({\xi }_{1}+i{\xi }_{2})\sqrt{{P}_{J}(k)}$ with Gaussian random variables ${\xi }_{1},{\xi }_{2}\sim N(0,1)$.

#### **JONSWAP Spectrum ${P}_{J}(k)$**

**$${P}_{J}(k)=\frac{\alpha {g}^{2}}{\parallel k\parallel {}^{5}}\exp \left({-\frac{5}{4}{\left({\frac{{\omega }_{p}}{\omega (k)}}\right)}^{4}}\right)\cdot {\gamma }^{\exp \left({-\frac{(\omega (k)-{\omega }_{p}{)}^{2}}{2{\sigma }^{2}{\omega }_{p}^{2}}}\right)}\cdot D(\theta )$$**

> * ${\omega }_{p}$: Peak frequency of the wind field.  
> * $\gamma$: Peak enhancement parameter (typically $3.3$).  
> * $D(\theta )$: Directional spreading function (${\cos }^{2s}(\frac{\theta -{\theta }_{wind}}{2})$).

### **3.2 Snell’s Law, Refraction, and Water Absorption**

Light entering water undergoes absorption and scattering according to the Beer-Lambert Law.

$$I(depth)={I}_{0}\cdot \exp (-{\beta }_{water}\cdot depth)$$

Where \$\\mathbf{\\beta}\_{\\text{water}} \= \\begin{bmatrix} \\beta\_r & \\beta\_g & \\beta\_b \\end{bmatrix}^T\$ accounts for wavelength-dependent attenuation (${\beta }_{r}\gg {\beta }_{g}>{\beta }_{b}$).  
Refraction rays ${v}_{refract}$ are computed using Snell's Law with ${n}_{air}=1.0$ and ${n}_{water}=1.333$:

$${v}_{refract}=\frac{{\eta }_{1}}{{\eta }_{2}}v+\left({\frac{{\eta }_{1}}{{\eta }_{2}}\cos {\theta }_{i}-\sqrt{1-{\left({\frac{{\eta }_{1}}{{\eta }_{2}}}\right)}^{2}(1-{\cos }^{2}{\theta }_{i})}}\right)n$$

## **4\. Lighting Engine Architecture (Clustered Forward+)**

To handle thousands of dynamic lights (flames, light shafts, spell effects) alongside sun/moon directional lights, the engine uses **Clustered Forward+ Shading**.

### **4.1 Frustum Grid Clustering**

The camera frustum is subdivided into a 3D grid of clusters ($32\times 18\times 32$ along X, Y, and Z).  
Z-slice boundaries are partitioned exponentially to balance cluster sizes across logarithmic camera depth:

$${Z}_{i}={Z}_{near}\cdot {\left({\frac{{Z}_{far}}{{Z}_{near}}}\right)}^{\frac{i}{{N}_{Z}}}$$

where $i\in [0,{N}_{Z}]$ is the slice index and ${N}_{Z}=32$.

## **5\. GLSL Shader Implementations**

### **5.1 Precomputed Sky View LUT Compute Shader**

OpenGL Shading Language  
\#version 460 core

layout(local\_size\_x \= 16, local\_size\_y \= 16, local\_size\_z \= 1\) in;

layout(binding \= 0, rgba16f) uniform image2D u\_SkyViewLUT;

uniform vec3  u\_SunDirection;  
uniform vec3  u\_RayleighBeta;  
uniform float u\_MieBeta;  
uniform vec3  u\_CameraPos;  
uniform float u\_PlanetRadius;  
uniform float u\_AtmosphereRadius;

const float PI \= 3.14159265359;  
const int   RAY\_STEPS \= 32;

// Intersect ray with sphere  
vec2 raySphereIntersection(vec3 rayOrigin, vec3 rayDir, float sphereRadius) {  
    float b \= dot(rayOrigin, rayDir);  
    float c \= dot(rayOrigin, rayOrigin) \- sphereRadius \* sphereRadius;  
    float d \= b \* b \- c;  
    if (d \< 0.0) return vec2(-1.0);  
    float sqrtD \= sqrt(d);  
    return vec2(-b \- sqrtD, \-b \+ sqrtD);  
}

// Rayleigh Phase Function  
float rayleighPhase(float cosTheta) {  
    return (3.0 / (16.0 \* PI)) \* (1.0 \+ cosTheta \* cosTheta);  
}

// Cornette-Shanks Phase Function for Mie  
float miePhase(float cosTheta, float g) {  
    float g2 \= g \* g;  
    return (3.0 \* (1.0 \- g2) \* (1.0 \+ cosTheta \* cosTheta)) /   
           (8.0 \* PI \* (2.0 \+ g2) \* pow(1.0 \+ g2 \- 2.0 \* g \* cosTheta, 1.5));  
}

void main() {  
    ivec2 texCoord \= ivec2(gl\_GlobalInvocationID.xy);  
    vec2  size     \= vec2(imageSize(u\_SkyViewLUT));

    if (float(texCoord.x) \>= size.x || float(texCoord.y) \>= size.y) return;

    vec2 uv \= (vec2(texCoord) \+ 0.5) / size;

    // Map UV coordinates to zenith and azimuth angles  
    float azimuth \= uv.x \* 2.0 \* PI \- PI;  
    float viewZenith \= uv.y \* PI;

    vec3 rayDir \= vec3(  
        sin(viewZenith) \* cos(azimuth),  
        cos(viewZenith),  
        sin(viewZenith) \* sin(azimuth)  
    );

    vec3 rayOrigin \= u\_CameraPos \+ vec3(0.0, u\_PlanetRadius, 0.0);  
    vec2 hit \= raySphereIntersection(rayOrigin, rayDir, u\_AtmosphereRadius);

    if (hit.y \< 0.0) {  
        imageStore(u\_SkyViewLUT, texCoord, vec4(0.0));  
        return;  
    }

    float rayLength \= hit.y;  
    float stepSize  \= rayLength / float(RAY\_STEPS);

    vec3 inScatteredLight \= vec3(0.0);  
    vec3 opticalDepth \= vec3(0.0);

    float cosTheta \= dot(rayDir, u\_SunDirection);  
    float phaseR   \= rayleighPhase(cosTheta);  
    float phaseM   \= miePhase(cosTheta, 0.8);

    for (int i \= 0; i \< RAY\_STEPS; \++i) {  
        vec3  samplePos \= rayOrigin \+ rayDir \* ((float(i) \+ 0.5) \* stepSize);  
        float height    \= length(samplePos) \- u\_PlanetRadius;

        // Density profiles (Scale heights: HR \= 8000m, HM \= 1200m)  
        float rhoR \= exp(-max(0.0, height) / 8000.0);  
        float rhoM \= exp(-max(0.0, height) / 1200.0);

        vec3 stepExtinction \= (u\_RayleighBeta \* rhoR \+ vec3(u\_MieBeta) \* rhoM) \* stepSize;  
        opticalDepth \+= stepExtinction;

        vec3 transmittance \= exp(-opticalDepth);

        // Calculate Sun Transmittance from sample point  
        vec2 sunHit \= raySphereIntersection(samplePos, u\_SunDirection, u\_AtmosphereRadius);  
        float sunStepSize \= sunHit.y / 8.0;  
        vec3 sunOpticalDepth \= vec3(0.0);

        for (int j \= 0; j \< 8; \++j) {  
            vec3 sunSamplePos \= samplePos \+ u\_SunDirection \* ((float(j) \+ 0.5) \* sunStepSize);  
            float sunHeight   \= length(sunSamplePos) \- u\_PlanetRadius;  
            sunOpticalDepth \+= (u\_RayleighBeta \* exp(-max(0.0, sunHeight) / 8000.0) \+  
                                vec3(u\_MieBeta) \* exp(-max(0.0, sunHeight) / 1200.0)) \* sunStepSize;  
        }

        vec3 sunTransmittance \= exp(-sunOpticalDepth);  
        vec3 scatterR \= u\_RayleighBeta \* rhoR \* phaseR;  
        vec3 scatterM \= vec3(u\_MieBeta) \* rhoM \* phaseM;

        inScatteredLight \+= transmittance \* sunTransmittance \* (scatterR \+ scatterM) \* stepSize;  
    }

    imageStore(u\_SkyViewLUT, texCoord, vec4(inScatteredLight, 1.0));  
}

### **5.2 Physically Based Water Surface Shader**

OpenGL Shading Language  
\#version 460 core

in vec3 v\_WorldPosition;  
in vec2 v\_UV;  
in vec3 v\_Normal;

out vec4 FragColor;

uniform vec3 u\_CameraPosition;  
uniform vec3 u\_SunDirection;  
uniform vec3 u\_SunColor;

uniform sampler2D u\_SceneDepthTexture;  
uniform sampler2D u\_SceneColorTexture;  
uniform sampler2D u\_WaterDisplacementMap;  
uniform sampler2D u\_WaterNormalMap;

uniform vec2  u\_ScreenResolution;  
uniform float u\_WaterAbsorptionRed;  
uniform float u\_WaterAbsorptionGreen;  
uniform float u\_WaterAbsorptionBlue;

const float N\_AIR   \= 1.0;  
const float N\_WATER \= 1.333;

// Schlick's approximation for Fresnel reflectance  
float fresnelSchlick(float cosTheta, float F0) {  
    return F0 \+ (1.0 \- F0) \* pow(clamp(1.0 \- cosTheta, 0.0, 1.0), 5.0);  
}

void main() {  
    vec3 V \= normalize(u\_CameraPosition \- v\_WorldPosition);  
      
    // Sample high-frequency detail normal from FFT map and combine  
    vec3 detailNormal \= texture(u\_WaterNormalMap, v\_UV \* 10.0).rgb \* 2.0 \- 1.0;  
    vec3 N \= normalize(v\_Normal \+ detailNormal \* 0.3);

    float cosTheta \= max(0.0, dot(V, N));  
    float F0 \= pow((N\_AIR \- N\_WATER) / (N\_AIR \+ N\_WATER), 2.0); // \~0.02 for water  
    float fresnel \= fresnelSchlick(cosTheta, F0);

    // Screen-space texture coordinates  
    vec2 screenUV \= gl\_FragCoord.xy / u\_ScreenResolution;

    // Sample scene depth for optical underwater depth calculation  
    float depthVal \= texture(u\_SceneDepthTexture, screenUV).r;  
      
    // Convert depth buffer to linear depth in world meters  
    float zNDCC \= depthVal \* 2.0 \- 1.0;  
    float linearDepth \= (2.0 \* 0.1 \* 1000.0) / (1000.0 \+ 0.1 \- zNDCC \* (1000.0 \- 0.1));  
    float waterDepth  \= max(0.0, linearDepth \- length(v\_WorldPosition \- u\_CameraPosition));

    // Beer-Lambert light extinction under water  
    vec3 absorptionCoeffs \= vec3(u\_WaterAbsorptionRed, u\_WaterAbsorptionGreen, u\_WaterAbsorptionBlue);  
    vec3 extinction \= exp(-absorptionCoeffs \* waterDepth);

    // Refraction color from scene buffer with distorted UVs  
    vec2 distortedUV \= screenUV \+ N.xz \* 0.02 \* clamp(waterDepth, 0.0, 1.0);  
    vec3 refractColor \= texture(u\_SceneColorTexture, distortedUV).rgb \* extinction;

    // Reflection color (Sun Specular Highlights \- Cook-Torrance model)  
    vec3 H \= normalize(V \+ u\_SunDirection);  
    float NdotH \= max(0.0, dot(N, H));  
    float specularTerm \= pow(NdotH, 256.0) \* 1.5; // High exponent for glossy sun glint  
    vec3 reflectColor \= u\_SunColor \* specularTerm;

    // Final water compositing  
    vec3 finalColor \= mix(refractColor, reflectColor, fresnel);  
    FragColor \= vec4(finalColor, 1.0);  
}
