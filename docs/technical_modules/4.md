# **Module 4 Technical Specification: Ground Micro-Detail, Soil & Gravel Simulation Engine**

## **1\. Mathematical Architecture & Micro-Geometry Formulations**

Macro and volumetric landforms (Modules 1–3) establish large-scale geometric features. Module 4 bridges the gap between macro features and close-up views (0.1–10 meters) by rendering micro-geometry—such as gravel beds, mud, pebbles, topsoil, and cracked clay—without linear texture bleeding or flat plane artifacts.

### **1.1 Height-Aware Splatmap Blending**

Traditional alpha-blend splatmapping interpolates material layers linearly ($C=\sum\limits_{}^{}{w}_{i}{C}_{i}$), producing unnatural semi-transparent cross-fades where rock surfaces float inside mud textures. Height-aware blending incorporates the physical height map ${H}_{i}(u,v)\in [0,1]$ of each candidate surface texture $i$ alongside its target distribution weight ${A}_{i}(u,v)$ (derived from erosion flow, slope, and altitude maps).  
The modified height score ${W}_{i}$ for layer $i$ is defined as:

$${W}_{i}=\max\limits_{}\left({0,{A}_{i}+{H}_{i}-M+\epsilon }\right)$$

$$M=\max\limits_{j}\left({{A}_{j}+{H}_{j}}\right)-{C}_{contrast}$$

Where:

> * ${C}_{contrast}\in (0.0,0.2]$: Controls the transition width / sharpness between material boundaries. Small values create razor-sharp boundaries where gravel protrudes directly out of mud.  
> * $\epsilon$: Small positive offset ($1{0}^{-5}$) preventing division by zero.

Final normalized material blend weights ${w}_{i}$ are computed via:

$${w}_{i}=\frac{{W}_{i}}{\sum\limits_{k=0}^{N-1}{W}_{k}}$$

### **1.2 Parallax Occlusion Mapping (POM) with Self-Shadowing**

For medium-to-close viewing distances where tessellation vertex evaluation is memory- or performance-constrained, Parallax Occlusion Mapping constructs per-pixel surface height displacement via view-space raymarching through height maps $H(u,v)$.

#### **1\. View-Space Raymarching**

Given normalized tangent-space view vector ${V}_{tan}=({V}_{x},{V}_{y},{V}_{z})$, the UV displacement step vector $\Delta uv$ per slice is:

$$\Delta uv=\frac{{V}_{xy}}{{V}_{z}}\cdot \frac{{h}_{depth}}{{N}_{steps}}$$

Where ${N}_{steps}$ dynamically scales with viewing angle to balance performance and eliminate slicing artifacts:

\$\$N\_{\\text{steps}} \= \\text{mix}\\left( N\_{\\text{max}}, N\_{\\text{min}}, \\vert{}\\mathbf{V} \\cdot \\mathbf{N}\\vert{} \\right)\$\$  
Ray stepping locates the first heightmap intersection where ray height ${z}_{ray}$ falls below texture displacement height $H(u{v}_{k})$:

$$u{v}^{*}=u{v}_{k-1}+\Delta uv\cdot \left({\frac{H(u{v}_{k-1})-{z}_{ray,k-1}}{(H(u{v}_{k-1})-{z}_{ray,k-1})+({z}_{ray,k}-H(u{v}_{k}))}}\right)$$

#### **2\. Tangent-Space Self-Shadowing**

Self-shadowing evaluates a secondary light-ray step sequence starting from displaced coordinate $u{v}^{*}$ along tangent-space light vector ${L}_{tan}$:

\$\$S \= \\max\_{j=1}^{M\_{\\text{steps}}} \\left( \\frac{H(\\mathbf{uv}^\* \+ \\Delta \\mathbf{uv}\_L \\cdot j) \- z\_{\\text{light}, j}}{j \\cdot \\Delta z\_L} \\cdot k\_{\\text{softness}} \\right)\$\$

$$ShadowFactor=clamp(1.0-S,0.0,1.0)$$

### **1.3 Hardware Tessellation & Dynamic Displacement**

At close range ($\leq 10m$), physical geometry is displaced dynamically along surface normals $N$ using hardware hull/domain tessellation compute passes:

$${p}_{displaced}={p}_{vertex}+N\cdot \left({\sum\limits_{i=0}^{N-1}{w}_{i}{H}_{i}(u{v}_{i})\cdot {d}_{max}}\right)$$

Tessellation factors ${T}_{edge}$ scale continuously based on screen-space edge length or viewer distance ${D}_{camera}$ to prevent visual popping:

$${T}_{edge}=clamp\left({\frac{{D}_{max}-{D}_{camera}}{{D}_{max}-{D}_{min}},0.0,1.0}\right)\cdot {T}_{max}$$

## **2\. Soil & Sediment Accumulation Mapping**

Material distribution weights ${A}_{i}(p)$ are driven directly by the sediment, flow, slope, and altitude outputs generated in Modules 1–3:

\$\$\\mathbf{A}(\\mathbf{p}) \= \\begin{bmatrix} A\_{\\text{mud}} \\\\ A\_{\\text{gravel}} \\\\ A\_{\\text{rock}} \\\\ A\_{\\text{soil}} \\end{bmatrix} \= \\begin{bmatrix} \\text{clamp}(\\text{FlowMap} \\cdot \\text{Moisture}, 0, 1\) \\\\ \\text{clamp}(\\text{TalusMap} \\cdot (1 \- \\text{Slope}), 0, 1\) \\\\ \\text{smoothstep}(\\theta\_{\\text{rock}}, 90^\\circ, \\text{Slope}) \\\\ \\text{clamp}(\\text{SedimentMap} \\cdot (1 \- \\text{FlowMap}), 0, 1\) \\end{bmatrix}\$\$

## **3\. Production GLSL Implementation: Height-Aware POM Fragment Shader**

The shader below executes height-aware multi-layer splatmapping along with Parallax Occlusion Mapping and self-shadowing.

OpenGL Shading Language  
\#version 450 core

in vec3 v\_WorldPos;  
in vec3 v\_Normal;  
in vec2 v\_UV;  
in vec3 v\_Tangent;  
in vec3 v\_Bitangent;

out vec4 FragColor;

// \----------------------------------------------------------------------------  
// BINDINGS & TEXTURE ARRAYS  
// \----------------------------------------------------------------------------  
// Texture arrays: \[0\] Mud, \[1\] Gravel, \[2\] Rock, \[3\] Topsoil  
layout(binding \= 0\) uniform sampler2DArray u\_AlbedoArray;  
layout(binding \= 1\) uniform sampler2DArray u\_NormalArray;  
layout(binding \= 2\) uniform sampler2DArray u\_HeightArray;  
layout(binding \= 3\) uniform sampler2D u\_FlowAndSedimentMap; // From Module 2

layout(push\_constant) uniform MicroDetailParams {  
    vec3 u\_CameraPos;  
    vec3 u\_LightDir;  
    float u\_POMHeightScale;   // Depth scale in meters (e.g. 0.05 to 0.15)  
    float u\_MinPOMSteps;       // Min ray steps (e.g. 8\)  
    float u\_MaxPOMSteps;       // Max ray steps (e.g. 32\)  
    float u\_Contrast;          // Height-aware blending contrast (e.g. 0.08)  
    float u\_UVScaling;         // Micro detail UV repetition factor (e.g. 10.0)  
} params;

// \----------------------------------------------------------------------------  
// HEIGHT-AWARE SPLATMAP WEIGHT COMPUTATION  
// \----------------------------------------------------------------------------  
vec4 ComputeHeightAwareWeights(vec4 alphaWeights, vec4 heights) {  
    vec4 modifiedHeights \= alphaWeights \+ heights;  
    float maxHeight \= max(max(modifiedHeights.r, modifiedHeights.g),   
                          max(modifiedHeights.b, modifiedHeights.a));  
      
    vec4 adjustedWeights \= max(vec4(0.0), modifiedHeights \- vec4(maxHeight \- params.u\_Contrast));  
    float sumWeights \= adjustedWeights.r \+ adjustedWeights.g \+ adjustedWeights.b \+ adjustedWeights.a \+ 0.00001;  
      
    return adjustedWeights / sumWeights;  
}

// \----------------------------------------------------------------------------  
// PARALLAX OCCLUSION MAPPING (POM)  
// \----------------------------------------------------------------------------  
vec2 RaymarchPOM(vec2 uv, vec3 viewDirTan, vec4 layerWeights, out float finalDisplacement) {  
    float numSteps \= mix(params.u\_MaxPOMSteps, params.u\_MinPOMSteps, abs(dot(vec3(0.0, 0.0, 1.0), viewDirTan)));  
    float layerDepth \= 1.0 / numSteps;  
    float currentLayerDepth \= 0.0;

    vec2 P \= viewDirTan.xy \* params.u\_POMHeightScale;  
    vec2 deltaTexCoords \= P / numSteps;

    vec2 currentTexCoords \= uv;  
      
    // Evaluate initial height  
    vec4 sampleHeights \= vec4(  
        texture(u\_HeightArray, vec3(currentTexCoords, 0)).r,  
        texture(u\_HeightArray, vec3(currentTexCoords, 1)).r,  
        texture(u\_HeightArray, vec3(currentTexCoords, 2)).r,  
        texture(u\_HeightArray, vec3(currentTexCoords, 3)).r  
    );  
    float currentHeightValue \= dot(sampleHeights, layerWeights);

    while (currentLayerDepth \< currentHeightValue) {  
        currentTexCoords \-= deltaTexCoords;  
        sampleHeights \= vec4(  
            texture(u\_HeightArray, vec3(currentTexCoords, 0)).r,  
            texture(u\_HeightArray, vec3(currentTexCoords, 1)).r,  
            texture(u\_HeightArray, vec3(currentTexCoords, 2)).r,  
            texture(u\_HeightArray, vec3(currentTexCoords, 3)).r  
        );  
        currentHeightValue \= dot(sampleHeights, layerWeights);  
        currentLayerDepth \+= layerDepth;  
    }

    // Interpolate offset (Secant method)  
    vec2 prevTexCoords \= currentTexCoords \+ deltaTexCoords;  
    float afterHeight \= currentHeightValue \- currentLayerDepth;  
      
    vec4 prevSampleHeights \= vec4(  
        texture(u\_HeightArray, vec3(prevTexCoords, 0)).r,  
        texture(u\_HeightArray, vec3(prevTexCoords, 1)).r,  
        texture(u\_HeightArray, vec3(prevTexCoords, 2)).r,  
        texture(u\_HeightArray, vec3(prevTexCoords, 3)).r  
    );  
    float prevHeightValue \= dot(prevSampleHeights, layerWeights);  
    float beforeHeight \= prevHeightValue \- currentLayerDepth \+ layerDepth;

    float weight \= afterHeight / (afterHeight \- beforeHeight);  
    finalDisplacement \= currentLayerDepth \- mix(0.0, layerDepth, weight);  
      
    return mix(currentTexCoords, prevTexCoords, weight);  
}

// \----------------------------------------------------------------------------  
// MAIN SHADER EXECUTION  
// \----------------------------------------------------------------------------  
void main() {  
    // 1\. Construct Tangent Space Basis Matrix  
    vec3 N \= normalize(v\_Normal);  
    vec3 T \= normalize(v\_Tangent);  
    vec3 B \= normalize(v\_Bitangent);  
    mat3 TBN \= transpose(mat3(T, B, N));

    vec3 viewDirWorld \= normalize(params.u\_CameraPos \- v\_WorldPos);  
    vec3 viewDirTan \= normalize(TBN \* viewDirWorld);

    // 2\. Fetch Material Distribution Maps from Module 2 Flow Data  
    vec4 flowData \= texture(u\_FlowAndSedimentMap, v\_UV);  
    float slope \= 1.0 \- clamp(dot(N, vec3(0.0, 0.0, 1.0)), 0.0, 1.0);

    // Derive raw distribution weights (A\_i)  
    vec4 alphaWeights;  
    alphaWeights.r \= clamp(flowData.r \* 2.0, 0.0, 1.0);              // Mud (Flow channels)  
    alphaWeights.g \= clamp(flowData.g \* (1.0 \- slope), 0.0, 1.0);    // Gravel (Talus sediment)  
    alphaWeights.b \= smoothstep(0.3, 0.7, slope);                    // Rock (Steep slopes)  
    alphaWeights.a \= clamp((1.0 \- alphaWeights.r) \* (1.0 \- alphaWeights.b), 0.0, 1.0); // Soil

    vec2 microUV \= v\_UV \* params.u\_UVScaling;

    // 3\. Perform Height-Aware Raymarching POM  
    float displacementDepth;  
    vec2 displacedUV \= RaymarchPOM(microUV, viewDirTan, alphaWeights, displacementDepth);

    // 4\. Evaluate Final Height-Aware Blending at Displaced UVs  
    vec4 heights \= vec4(  
        texture(u\_HeightArray, vec3(displacedUV, 0)).r,  
        texture(u\_HeightArray, vec3(displacedUV, 1)).r,  
        texture(u\_HeightArray, vec3(displacedUV, 2)).r,  
        texture(u\_HeightArray, vec3(displacedUV, 3)).r  
    );  
    vec4 blendWeights \= ComputeHeightAwareWeights(alphaWeights, heights);

    // 5\. Sample & Blend Composite Material Textures  
    vec3 albedo \= vec3(0.0);  
    vec3 tangentNormal \= vec3(0.0);

    for (int i \= 0; i \< 4; \++i) {  
        if (blendWeights\[i\] \> 0.001) {  
            albedo \+= texture(u\_AlbedoArray, vec3(displacedUV, i)).rgb \* blendWeights\[i\];  
            vec3 n \= texture(u\_NormalArray, vec3(displacedUV, i)).rgb \* 2.0 \- 1.0;  
            tangentNormal \+= n \* blendWeights\[i\];  
        }  
    }

    // Transform blended tangent normal to world space  
    vec3 worldNormal \= normalize(mat3(T, B, N) \* tangentNormal);

    // Simple Diffuse Lighting Calculation  
    float NdotL \= max(dot(worldNormal, normalize(-params.u\_LightDir)), 0.1);

    FragColor \= vec4(albedo \* NdotL, 1.0);  
}

## **4\. Parameter Specification Table**

| Parameter Name | Symbol | Range / Units | Recommended Default | Physical Effect / Description |
| :---- | :---- | :---- | :---- | :---- |
| **Height Contrast** | **${C}_{contrast}$** | $0.01-0.20$ | $0.08$ | Transition width between materials. Low values yield sharp stone/mud boundaries. |
| **POM Height Scale** | **${h}_{depth}$** | $0.02-0.20$ $m$ | $0.08$ $m$ | Depth of physical parallax displacement in world units. |
| **Micro UV Tile Scale** | **${S}_{UV}$** | $5.0-50.0$ | $15.0$ | Tiling frequency for micro-detail texture arrays across macro terrain geometry. |
| **Tessellation Range** | **${D}_{min},{D}_{max}$** | $2.0-50.0$ $m$ | $[5.0,25.0]$ $m$ | Near/far camera distances defining where dynamic mesh tessellation activates. |
| **Max Ray Step Count** | **${N}_{max}$** | $16-64$ (Steps) | $32$ | Maximum raymarching iterations used in POM at steep grazing angles. |
