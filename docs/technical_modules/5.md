## **2\. Mathematical Foundation & Biome Niche Modeling**

Vegetation species survival and density functions are computed as multidimensional ecological niche probability fields over continuous terrain coordinates $x=(x,y,z)\in {R}^{3}$.

### **2.1 Environmental Input Vector**

For any point $x$, the environmental parameters are defined as the vector:

\$\$\\mathbf{E}(\\mathbf{x}) \= \\begin{bmatrix} h(\\mathbf{x}) & s(\\mathbf{x}) & a(\\mathbf{x}) & m(\\mathbf{x}) & n(\\mathbf{x}) \\end{bmatrix}^T\$\$  
Where:

> * $h(x)\in [{h}_{\min\limits_{}},{h}_{\max\limits_{}}]$: Elevation above sea level.  
> * $s(x)=\arccos (n(x)\cdot \hat{z})\in [0,\pi /2]$: Terrain slope angle derived from surface normal $n(x)$.  
> * $a(x)=\arctan 2({n}_{y},{n}_{x})\in [-\pi ,\pi ]$: Terrain aspect orientation.

> $m(x)\in [0,1]$: Soil moisture content modeled via Topographic Wetness Index (TWI):

> $$TWI=\ln \left({\frac{\alpha }{\tan \beta }}\right)$$

> *   
>   where $\alpha$ is the specific catchment area and $\beta$ is the local slope.  
> * $n(x)\in [0,1]$: Soil nutrient index derived from geology maps and organic sediment accumulation models.

### **2.2 Species Suitability Function (Whittaker & Shelford's Law)**

The occurrence probability ${P}_{s}(E)$ for a given species $s$ is modeled using a modified Shelford’s Law of Tolerance via a general asymmetric Gaussian response product:

$${P}_{s}(E(x))=\prod\limits_{i\in \{h,s,a,m,n\}}^{}{R}_{s,i}({E}_{i}(x))$$

Where the individual factor response curve ${R}_{s,i}(v)$ is given by:

$${R}_{s,i}(v)=\exp \left({-\frac{(v-{\mu }_{s,i}{)}^{2}}{2\cdot ({\sigma }_{s,i}^{-}{)}^{2}\cdot \theta ({\mu }_{s,i}-v)+2\cdot ({\sigma }_{s,i}^{+}{)}^{2}\cdot \theta (v-{\mu }_{s,i})}}\right)$$

> * ${\mu }_{s,i}$: Optimal environmental value for attribute $i$.  
> * ${\sigma }_{s,i}^{-},{\sigma }_{s,i}^{+}$: Left and right variance bounds allowing asymmetric tolerance curves.  
> * $\theta (x)$: Heaviside step function ($\theta (x)=1$ if $x\geq 0$, else $0$).

### **2.3 Solar Insolation Aspect Bias**

Aspect solar radiation weight ${W}_{solar}$ scales moisture depletion and temperature according to hemisphere latitude $\phi$:

$${W}_{solar}(a,s)=\sin (s)\cdot \cos (\phi )\cdot \cos (a-{a}_{equator})+\cos (s)\cdot \sin (\phi )$$

where ${a}_{equator}=0$ (North, for Southern Hemisphere) or $\pi$ (South, for Northern Hemisphere).

## **3\. Poisson Disk Sampling & Spatial Scattering**

To avoid unnatural alignment while maintaining physical exclusion zones (preventing overlapping trunks/roots), candidate positions are generated using a variable-radius GPU Poisson Disk Sampler based on parallel spatial grid hashing.

### **3.1 Variable Distance Condition**

The minimum distance ${R}_{ab}(x)$ required between two adjacent plants of species $a$ and species $b$ at location $x$ is defined by their dynamic interaction radii:

$${R}_{ab}(x)={r}_{a}\cdot {S}_{a}(x)+{r}_{b}\cdot {S}_{b}(x)+{\gamma }_{ab}$$

> * ${r}_{a},{r}_{b}$: Base physical radii at scale 1.0.  
> * ${S}_{a}(x),{S}_{b}(x)$: Local growth scale factors determined by suitability ${P}_{s}(E(x))$.  
> * ${\gamma }_{ab}$: Ecological competition coefficient matrix (${\gamma }_{ab}>0$ for inter-species inhibition, ${\gamma }_{ab}<0$ for symbiotic clustering).

### **3.2 Bridson Spatial Grid Hashing on GPU**

The domain is partitioned into a uniform 2D spatial grid where grid cell size ${r}_{grid}=\frac{{R}_{\min\limits_{}}}{\sqrt{2}}$. Each cell stores at most one sample index to enable $O(1)$ neighbor lookup within a $5\times 5$ cell neighborhood during GPU parallel sampling.

## **4\. Hierarchical Clustering & Multi-Tier Canopy**

Natural ecosystems exhibit vertical multi-tier hierarchy: **Overstory (Trees)** $\rightarrow$ **Understory (Saplings/Sub-canopy)** $\rightarrow$ **Shrub Layer** $\rightarrow$ **Ground Cover (Grass/Ferns/Moss)**.

\+--------------------------------------------------------------------------+  
| Overstory (Trees)       \[High Light, Deep Roots\]                         |  
|   |-- Canopy Shadow Mask                                                 |  
|   \+--\> Understory (Saplings)  \[Partial Shade, Competes for light\]       |  
|          |-- Root Exclusion Zone                                         |  
|          \+--\> Shrub Layer     \[Cluster-adapted to canopy drop-line\]     |  
|                 \+--\> Ground Cover (Grass/Moss) \[Moisture-dependent\]      |  
\+--------------------------------------------------------------------------+

### **4.1 Canopy Competition and Light Attenuation**

Overstory trees cast a dynamic canopy shade $S(x)$ onto lower layers:

$$S(x)=\sum\limits_{k\in Overstory}^{}{A}_{k}\cdot \exp \left({-\frac{\parallel {x}_{xy}-{x}_{k,xy}\parallel {}^{2}}{{R}_{k,crown}^{2}}}\right)$$

The modified suitability ${P}_{shrub}'(x)$ for shade-intolerant understory species is modulated by:

$${P}_{shrub}'(x)={P}_{shrub}(E(x))\cdot (1-\lambda \cdot S(x))$$

where $\lambda \in [0,1]$ is the species light suppression coefficient.

### **4.2 Seed Dispersal Clustering Model**

Ground cover and understory species exhibit clustered propagation around parent plants using a Thomas Cluster Process. Candidate locations ${x}_{child}$ relative to a parent location ${x}_{parent}$ are sampled via a Rayleigh distribution:

$$f(r;{\sigma }_{cluster})=\frac{r}{{\sigma }_{cluster}^{2}}\exp \left({-\frac{{r}^{2}}{2{\sigma }_{cluster}^{2}}}\right),\theta \sim U(0,2\pi )$$

\$\$\\mathbf{x}\_{\\text{child}} \= \\mathbf{x}\_{\\text{parent}} \+ \\begin{bmatrix} r \\cos \\theta \\\\ r \\sin \\theta \\\\ 0 \\end{bmatrix}\$\$

## **5\. GLSL Compute Shader Implementation**

### **5.1 Biome Evaluation & Spatial Hashing Shader**

OpenGL Shading Language  
\#version 460 core

layout(local\_size\_x \= 16, local\_size\_y \= 16, local\_size\_z \= 1\) in;

// Terrain & Biome Input Textures  
layout(binding \= 0\) uniform sampler2D u\_ElevationMap;  
layout(binding \= 1\) uniform sampler2D u\_NormalMap;  
layout(binding \= 2\) uniform sampler2D u\_MoistureMap;

struct SpeciesParam {  
    vec2 elevationRange; // min, max  
    vec2 slopeRange;     // min, max (radians)  
    vec2 moistureRange;  // min, max  
    float baseRadius;  
    float maxScale;  
    uint  speciesID;  
    float padding;  
};

layout(std430, binding \= 0\) buffer SpeciesBuffer {  
    SpeciesParam u\_SpeciesParams\[\];  
};

struct InstanceData {  
    vec4 positionScale; // xyz: world pos, w: scale  
    vec4 rotationInfo;    // Euler or Quaternion  
    uint speciesID;  
    uint flags;  
    vec2 pad;  
};

layout(std430, binding \= 1\) buffer OutputInstanceBuffer {  
    uint u\_InstanceCount;  
    InstanceData u\_Instances\[\];  
};

layout(std430, binding \= 2\) buffer SpatialGridBuffer {  
    int u\_GridCells\[\]; // Contains instance indices, \-1 if empty  
};

uniform vec2  u\_TerrainSize; // World dimensions  
uniform uvec2 u\_GridDimensions;  
uniform float u\_CellSize;  
uniform uint  u\_TotalSpecies;  
uniform uint  u\_Seed;

// PCG Hash for deterministic pseudo-random number generation  
uint pcg\_hash(uint seed) {  
    uint state \= seed \* 747796405u \+ 2891336453u;  
    uint word \= ((state \>\> ((state \>\> 28u) \+ 4u)) ^ state) \* 277803737u;  
    return (word \>\> 22u) ^ word;  
}

float randomFloat(inout uint seed) {  
    seed \= pcg\_hash(seed);  
    return float(seed) / 4294967295.0;  
}

// Evaluate Gaussian suitability  
float evaluateSuitability(float val, vec2 range) {  
    float center \= (range.x \+ range.y) \* 0.5;  
    float sigma  \= (range.y \- range.x) \* 0.25;  
    if (sigma \<= 0.0001) return 0.0;  
    float d \= (val \- center) / sigma;  
    return exp(-0.5 \* d \* d);  
}

ivec2 worldToGrid(vec2 worldPos) {  
    return ivec2(floor(worldPos / u\_CellSize));  
}

int gridTo1D(ivec2 gridPos) {  
    if (gridPos.x \< 0 || gridPos.x \>= int(u\_GridDimensions.x) ||  
        gridPos.y \< 0 || gridPos.y \>= int(u\_GridDimensions.y)) {  
        return \-1;  
    }  
    return gridPos.y \* int(u\_GridDimensions.x) \+ gridPos.x;  
}

void main() {  
    uvec2 globalIdx \= gl\_GlobalInvocationID.xy;  
    vec2 uv \= vec2(globalIdx) / vec2(gl\_NumWorkGroups.xy \* gl\_WorkGroupSize.xy);  
    if (uv.x \> 1.0 || uv.y \> 1.0) return;

    vec2 worldPos2D \= uv \* u\_TerrainSize;  
    float elevation \= texture(u\_ElevationMap, uv).r;  
    vec3 normal     \= texture(u\_NormalMap, uv).rgb \* 2.0 \- 1.0;  
    float moisture  \= texture(u\_MoistureMap, uv).r;  
    float slope     \= acos(clamp(dot(normal, vec3(0.0, 1.0, 0.0)), 0.0, 1.0));

    uint rngSeed \= globalIdx.y \* 1920u \+ globalIdx.x \+ u\_Seed;

    for (uint s \= 0u; s \< u\_TotalSpecies; \++s) {  
        SpeciesParam species \= u\_SpeciesParams\[s\];

        float pElev  \= evaluateSuitability(elevation, species.elevationRange);  
        float pSlope \= evaluateSuitability(slope, species.slopeRange);  
        float pMoist \= evaluateSuitability(moisture, species.moistureRange);

        float P \= pElev \* pSlope \* pMoist;  
        float rnd \= randomFloat(rngSeed);

        if (P \> 0.15 && rnd \< P) {  
            // Check Poisson Disk exclusion against spatial grid  
            ivec2 gridPos \= worldToGrid(worldPos2D);  
            bool candidateValid \= true;

            int searchRadius \= 2;  
            for (int dy \= \-searchRadius; dy \<= searchRadius; \++dy) {  
                for (int dx \= \-searchRadius; dx \<= searchRadius; \++dx) {  
                    ivec2 neighborCell \= gridPos \+ ivec2(dx, dy);  
                    int cell1D \= gridTo1D(neighborCell);  
                    if (cell1D \!= \-1) {  
                        int otherInstIdx \= u\_GridCells\[cell1D\];  
                        if (otherInstIdx \!= \-1) {  
                            InstanceData otherInst \= u\_Instances\[otherInstIdx\];  
                            float dist \= length(worldPos2D \- otherInst.positionScale.xz);  
                            float minDist \= species.baseRadius \+ u\_SpeciesParams\[otherInst.speciesID\].baseRadius;  
                            if (dist \< minDist) {  
                                candidateValid \= false;  
                                break;  
                            }  
                        }  
                    }  
                }  
                if (\!candidateValid) break;  
            }

            if (candidateValid) {  
                int targetCell1D \= gridTo1D(gridPos);  
                if (targetCell1D \!= \-1) {  
                    // Atomic grid occupancy claim  
                    int existingVal \= atomicCompareExchange(u\_GridCells\[targetCell1D\], \-1, 0);  
                    if (existingVal \== \-1) {  
                        uint writeIdx \= atomicAdd(u\_InstanceCount, 1u);  
                          
                        // Scale modulated by suitability  
                        float finalScale \= mix(0.5, species.maxScale, P);  
                          
                        InstanceData newInst;  
                        newInst.positionScale \= vec4(worldPos2D.x, elevation, worldPos2D.y, finalScale);  
                          
                        // Random rotation around Y axis  
                        float rotAngle \= randomFloat(rngSeed) \* 6.28318530718;  
                        newInst.rotationInfo \= vec4(0.0, sin(rotAngle \* 0.5), 0.0, cos(rotAngle \* 0.5));  
                        newInst.speciesID \= species.speciesID;  
                        newInst.flags \= 1u;

                        u\_Instances\[writeIdx\] \= newInst;  
                        u\_GridCells\[targetCell1D\] \= int(writeIdx);  
                        break; // One plant placement per grid invocation  
                    }  
                }  
            }  
        }  
    }  
}

### **5.2 GPU Instanced Indirect Culling & LOD Shader**

OpenGL Shading Language  
\#version 460 core

layout(local\_size\_x \= 64, local\_size\_y \= 1, local\_size\_z \= 1\) in;

struct DrawElementsIndirectCommand {  
    uint count;  
    uint instanceCount;  
    uint firstIndex;  
    int  baseVertex;  
    uint baseInstance;  
};

struct InstanceData {  
    vec4 positionScale;  
    vec4 rotationInfo;  
    uint speciesID;  
    uint flags;  
    vec2 pad;  
};

layout(std430, binding \= 0\) readonly buffer InputInstances {  
    InstanceData u\_AllInstances\[\];  
};

layout(std430, binding \= 1\) writeonly buffer VisibleInstances {  
    InstanceData u\_CulledInstances\[\];  
};

layout(std430, binding \= 2\) buffer IndirectCommands {  
    DrawElementsIndirectCommand u\_Commands\[\];  
};

uniform mat4  u\_ViewProjectionMatrix;  
uniform vec3  u\_CameraPosition;  
uniform vec4  u\_FrustumPlanes\[6\];  
uniform float u\_MaxDrawDistance;  
uniform float u\_LODDistanceThresholds\[3\];

bool isAABBInFrustum(vec3 minBound, vec3 maxBound) {  
    for (int i \= 0; i \< 6; \++i) {  
        vec3 p \= minBound;  
        if (u\_FrustumPlanes\[i\].x \>= 0.0) p.x \= maxBound.x;  
        if (u\_FrustumPlanes\[i\].y \>= 0.0) p.y \= maxBound.y;  
        if (u\_FrustumPlanes\[i\].z \>= 0.0) p.z \= maxBound.z;

        if (dot(u\_FrustumPlanes\[i\].xyz, p) \+ u\_FrustumPlanes\[i\].w \< 0.0) {  
            return false;  
        }  
    }  
    return true;  
}

void main() {  
    uint idx \= gl\_GlobalInvocationID.x;  
    if (idx \>= u\_AllInstances.length()) return;

    InstanceData inst \= u\_AllInstances\[idx\];  
    vec3 worldPos \= inst.positionScale.xyz;  
    float scale   \= inst.positionScale.w;

    // 1\. Distance Culling  
    float dist \= distance(u\_CameraPosition, worldPos);  
    if (dist \> u\_MaxDrawDistance) return;

    // 2\. Frustum Culling (Bounding Sphere approximation scaled to AABB)  
    float bboxRadius \= 2.0 \* scale; // Approximate mesh extent  
    vec3 minB \= worldPos \- vec3(bboxRadius);  
    vec3 maxB \= worldPos \+ vec3(bboxRadius);

    if (\!isAABBInFrustum(minB, maxB)) return;

    // 3\. LOD Selection  
    uint lodLevel \= 0u;  
    if (dist \> u\_LODDistanceThresholds\[1\]) {  
        lodLevel \= 2u;  
    } else if (dist \> u\_LODDistanceThresholds\[0\]) {  
        lodLevel \= 1u;  
    }

    // 4\. Append to Indirect Command Buffer & Packed Instance Data  
    uint cmdIndex \= inst.speciesID \* 3u \+ lodLevel; // 3 LODs per species  
    uint outInstanceIdx \= atomicAdd(u\_Commands\[cmdIndex\].instanceCount, 1u);  
    uint globalOutOffset \= u\_Commands\[cmdIndex\].baseInstance \+ outInstanceIdx;

    u\_CulledInstances\[globalOutOffset\] \= inst;  
}
