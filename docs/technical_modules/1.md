# **Module 1 Technical Specification: Macro Landform & Tectonic Elevation Engine**

## **1\. Mathematical Architecture & Core Formulations**

The Macro Landform Engine operates as a continuous, procedural multi-scale vector evaluation function \$H(\\mathbf{p}) : \\mathbb{R}^2 \\to \\mathbb{R}\$, where \$\\mathbf{p} \= (x, y)\$ represents global terrain coordinates in world space.

### **1.1 Continental Elevation Curve Spline**

To establish geomorphologically accurate macro boundaries (separating abyssal oceanic trenches, continental shelves, coastal lowlands, rolling foothills, and high alpine mountain chains), raw height maps pass through a piece-wise continuous monotonic cubic Hermite spline \$S(h)\$.

\$\$S(h) \= \\begin{cases} h\_{\\text{trench}} \+ (h\_{\\text{shelf}} \- h\_{\\text{trench}}) \\cdot k\_{\\text{oceanic}}(h), & h \< h\_{\\text{coast}} \\\\ h\_{\\text{coast}} \+ (h\_{\\text{alpine}} \- h\_{\\text{coast}}) \\cdot k\_{\\text{land}}(h), & h \\ge h\_{\\text{coast}} \\end{cases}\$\$  
Where the normalized interpolation factors \$k(h)\$ are shaped via smoothstep curves with variable slope tension \$T\$:

\$\$k(h) \= 3 \\left(\\frac{h \- h\_0}{h\_1 \- h\_0}\\right)^2 \- 2 \\left(\\frac{h \- h\_0}{h\_1 \- h\_0}\\right)^3\$\$

### **1.2 Domain Warping (Tectonic Fault Line Simulation)**

Standard isotropic multi-octave noise produces uniform "rolling hills." To simulate non-linear directional tectonic compressional forces (folding and fault lines), global evaluation coordinates \$\\mathbf{p}\$ are vector-shifted using low-frequency multi-octave gradient noise vectors \$\\mathbf{D}(\\mathbf{p}) \= (D\_x(\\mathbf{p}), D\_y(\\mathbf{p}))\$.

\$\$\\mathbf{p}' \= \\mathbf{p} \+ \\alpha \\cdot \\mathbf{D}(\\mathbf{p})\$\$

\$\$\\mathbf{D}(\\mathbf{p}) \= \\left( N(\\mathbf{p} \+ \\mathbf{\\delta}\_x), N(\\mathbf{p} \+ \\mathbf{\\delta}\_y) \\right)\$\$

> * \$\\alpha\$: Warping strength vector controlling fault line displacement amplitude.  
> * \$\\mathbf{\\delta}\_x, \\mathbf{\\delta}\_y\$: Phase offset constants (\$\\mathbf{\\delta}\_x \= (0.0, 0.0)\$, \$\\mathbf{\\delta}\_y \= (5.2, 1.3)\$) preventing axis-aligned diagonal artifacting.

### **1.3 Sharp Ridge Noise & Billow Formations**

Tectonic ridges and sharp alpine arretes are generated using transformed multi-octave absolute gradient noise (Ridge Noise). The absolute value operation produces sharp \$C^0\$-continuous troughs, which are inverted to create knife-edge ridge crests:

\$\$R(\\mathbf{p}) \= \\left( 1.0 \- \\left\\vert{} N(\\mathbf{p}) \\right\\vert{} \\right)^d\$\$  
Where \$d \\in \[1.0, 3.0\]\$ is the **ridge sharpness exponent**. Higher values sharpen mountain crests while flattening valley floors.  
To introduce structural variance across octaves, ridge noise amplitude attenuation is modulated dynamically by lower-frequency octave heights (Self-Attenuation):

\$\$H\_{\\text{ridge}}(\\mathbf{p}) \= \\sum\_{i=0}^{O-1} A\_i \\cdot \\left( 1.0 \- \\left\\vert{} N(f\_i \\cdot \\mathbf{p}') \\right\\vert{} \\right)^d \\cdot w\_i\$\$

\$\$w\_{i+1} \= \\text{clamp}(w\_i \\cdot R\_i(\\mathbf{p}'), 0.0, 1.0), \\quad w\_0 \= 1.0\$\$

> * \$O\$: Total octaves (\$O \\ge 8\$).  
> * \$f\_i \= f\_0 \\cdot \\text{lacunarity}^i\$: Frequency per octave.  
> * \$A\_i \= A\_0 \\cdot \\text{gain}^i\$: Amplitude per octave.

## **2\. Algorithm & Pipeline Breakdown**

The generation pipeline executes in four sequential stages per vertex/texel:

┌────────────────────────────────────────┐  
│     Global Space Coordinates (x, y)     │  
└───────────────────┬────────────────────┘  
                    │  
                    ▼  
┌────────────────────────────────────────┐  
│       Stage 1: Continental Mask        │  
│   Low-frequency simplex/cellular noise  │  
└───────────────────┬────────────────────┘  
                    │  
                    ▼  
┌────────────────────────────────────────┐  
│    Stage 2: Directional Domain Warp    │  
│  Tectonic displacement vector field    │  
└───────────────────┬────────────────────┘  
                    │  
                    ▼  
┌────────────────────────────────────────┐  
│  Stage 3: Multi-Octave Ridge Noise     │  
│   Sharpening \+ Dynamic Self-Atten.     │  
└───────────────────┬────────────────────┘  
                    │  
                    ▼  
┌────────────────────────────────────────┐  
│  Stage 4: Spline Curve Remapping       │  
│ Global Elevation Curve & Alpine Peak   │  
└────────────────────────────────────────┘

## **3\. Production GLSL Compute / Fragment Implementation**

The implementation below demonstrates a complete GLSL evaluation function designed for compute shader heightmap baking or direct vertex evaluation in HLSL/GLSL.

OpenGL Shading Language  
\#version 450 core

// \----------------------------------------------------------------------------  
// CONSTANTS & PARAMETER RANGES  
// \----------------------------------------------------------------------------  
const int OCTAVES \= 10;  
const float LACUNARITY \= 2.05;  
const float GAIN \= 0.48;

// Configurable Uniforms / Push Constants  
layout(push\_constant) uniform LandformParams {  
    float u\_globalScale;       // Range: 0.00005 to 0.0005 (World frequency)  
    float u\_warpStrength;      // Range: 10.0 to 150.0 (Tectonic displacement)  
    float u\_ridgeSharpness;    // Range: 1.0 to 3.0 (Ridge crest sharpening)  
    float u\_mountainHeight;    // Range: 500.0 to 4000.0 (Max meters elevation)  
} params;

// \----------------------------------------------------------------------------  
// NOISE UTILITIES (Fast 2D Simplex Noise Derivative Approximation)  
// \----------------------------------------------------------------------------  
vec2 hash22(vec2 p) {  
    p \= vec2(dot(p, vec2(127.1, 311.7)), dot(p, vec2(269.5, 183.3)));  
    return \-1.0 \+ 2.0 \* fract(sin(p) \* 43758.5453123);  
}

float simplexNoise(vec2 p) {  
    const float K1 \= 0.366025403; // (sqrt(3)-1)/2  
    const float K2 \= 0.211324865; // (3-sqrt(3))/6

    vec2 i \= floor(p \+ (p.x \+ p.y) \* K1);  
    vec2 a \= p \- i \+ (i.x \+ i.y) \* K2;  
    vec2 o \= (a.x \> a.y) ? vec2(1.0, 0.0) : vec2(0.0, 1.0);  
    vec2 b \= a \- o \+ K2;  
    vec2 c \= a \- 1.0 \+ 2.0 \* K2;

    vec3 h \= max(0.5 \- vec3(dot(a, a), dot(b, b), dot(c, c)), 0.0);  
    vec3 n \= h \* h \* h \* h \* vec3(  
        dot(a, hash22(i)),  
        dot(b, hash22(i \+ o)),  
        dot(c, hash22(i \+ 1.0))  
    );

    return dot(n, vec3(70.0));  
}

// \----------------------------------------------------------------------------  
// STAGE 2: DOMAIN WARP FUNCTION (Simulating Tectonic Shear Lines)  
// \----------------------------------------------------------------------------  
vec2 calculateDomainWarp(vec2 pos) {  
    vec2 offsetA \= vec2(0.0, 0.0);  
    vec2 offsetB \= vec2(5.2, 1.3);

    float qx \= simplexNoise(pos \+ offsetA);  
    float qy \= simplexNoise(pos \+ offsetB);

    return vec2(qx, qy);  
}

// \----------------------------------------------------------------------------  
// STAGE 4: CONTINENTAL ELEVATION SPLINE REMAPPING  
// \----------------------------------------------------------------------------  
float applyContinentalCurve(float rawHeight) {  
    // Height thresholds normalized \[-1, 1\] \-\> \[0, 1\]  
    float h \= rawHeight \* 0.5 \+ 0.5;

    float abyssalShelf \= 0.25;  
    float coastLine    \= 0.40;  
    float foothills    \= 0.60;

    if (h \< coastLine) {  
        // Ocean Basin to Continental Shelf  
        float t \= clamp(h / coastLine, 0.0, 1.0);  
        return mix(-0.2, 0.0, t \* t);  
    } else if (h \< foothills) {  
        // Coastal Lowlands to Rolling Hills  
        float t \= clamp((h \- coastLine) / (foothills \- coastLine), 0.0, 1.0);  
        return mix(0.0, 0.15, smoothstep(0.0, 1.0, t));  
    } else {  
        // High Alpine Mountain Ranges  
        float t \= clamp((h \- foothills) / (1.0 \- foothills), 0.0, 1.0);  
        return mix(0.15, 1.0, pow(t, 1.5));  
    }  
}

// \----------------------------------------------------------------------------  
// MASTER EVALUATION FUNCTION  
// \----------------------------------------------------------------------------  
float EvaluateMacroTerrainHeight(vec2 worldPos) {  
    vec2 st \= worldPos \* params.u\_globalScale;

    // 1\. Continental Base Mask (Ultra low frequency)  
    float continentalMask \= simplexNoise(st \* 0.2);

    // 2\. Domain Warping (Tectonic Strain Lines)  
    vec2 warpVector \= calculateDomainWarp(st \* 0.5);  
    vec2 warpedST \= st \+ warpVector \* (params.u\_warpStrength \* params.u\_globalScale);

    // 3\. Multi-Octave Ridge Noise with Dynamic Attenuation  
    float elevation \= 0.0;  
    float frequency \= 1.0;  
    float amplitude \= 1.0;  
    float weight \= 1.0;

    for (int i \= 0; i \< OCTAVES; \++i) {  
        // Evaluate Simplex Noise  
        float n \= simplexNoise(warpedST \* frequency);

        // Convert to Inverted Ridge Noise  
        float ridge \= 1.0 \- abs(n);  
        ridge \= pow(ridge, params.u\_ridgeSharpness);

        // Accumulate weighted octave  
        elevation \+= ridge \* amplitude \* weight;

        // Modulate next octave weight by current octave output (Self-Attenuation)  
        weight \= clamp(ridge \* 1.2, 0.0, 1.0);

        frequency \*= LACUNARITY;  
        amplitude \*= GAIN;  
    }

    // 4\. Combine Base Macro Shapes and Apply Spline Remapping  
    float combinedRawHeight \= elevation \* 0.7 \+ continentalMask \* 0.3;  
    float finalNormalizedHeight \= applyContinentalCurve(combinedRawHeight);

    // Scale to physical world meters  
    return finalNormalizedHeight \* params.u\_mountainHeight;  
}

## **4\. Parameter Specification Table**

To reproduce photorealistic landforms without causing extreme topological deformation or high-frequency noise aliasing, parameter values should stay within these bounds:

| Parameter Name | Target Symbol | Range / Units | Recommended Default | Physical Effect / Description |
| :---- | :---- | :---- | :---- | :---- |
| **Global World Scale** | \$f\_0\$ | \$0.00002 \- 0.0005\$ \$\\text{m}^{-1}\$ | \$0.0001\$ \$\\text{m}^{-1}\$ | Defines the spatial scale of continental features and mountain broadness. |
| **Domain Warp Strength** | \$\\alpha\$ | \$20.0 \- 200.0\$ \$\\text{m}\$ | \$80.0\$ \$\\text{m}\$ | Controls horizontal shear displacement. High values create twisted, folded tectonic plates. |
| **Ridge Sharpness Exponent** | \$d\$ | \$1.0 \- 3.0\$ | \$2.2\$ | Higher values create razor-sharp arretes; lower values soften peaks into rounded crests. |
| **Octave Count** | \$O\$ | \$8 \- 12\$ (Integer) | \$10\$ | Total noise passes. \$10\$ octaves cover features from \$10\\,\\text{km}\$ down to \$\\sim10\\,\\text{m}\$. |
| **Lacunarity** | \$\\text{lac}\$ | \$1.8 \- 2.2\$ | \$2.05\$ | Multiplier for spatial frequency between octaves. \$2.05\$ prevents diagonal symmetry repetition. |
| **Persistence / Gain** | \$g\$ | \$0.40 \- 0.55\$ | \$0.48\$ | Amplitude scaling factor per octave. Higher values create rougher, more jagged surfaces. |
| **Alpine Height Scale** | \$H\_{\\text{max}}\$ | \$1000.0 \- 8000.0\$ \$\\text{m}\$ | \$2500.0\$ \$\\text{m}\$ | Absolute vertical displacement scale in real-world meters. |
