# **Module 3 Technical Specification: Geology, Rock Stratification & Volumetric Cliff Engine**

## **1\. Mathematical Architecture & Volumetric Formulations**

Standard 2D heightmaps \$H(x, y)\$ cannot represent non-manifold topology such as overhanging cliffs, sea caves, rock arches, or undercut riverbanks without severe texture stretching or vertex degeneration. Module 3 evaluates a continuous 3D scalar density field \$D(\\mathbf{p}) : \\mathbb{R}^3 \\to \\mathbb{R}\$ where \$\\mathbf{p} \= (x, y, z)\$ represents 3D world space coordinates.  
The isosurface bounding rock substrate against atmosphere is defined at \$D(\\mathbf{p}) \= 0\$:

\$\$\\text{Surface} \= \\{ \\mathbf{p} \\in \\mathbb{R}^3 \\mid D(\\mathbf{p}) \= 0 \\}\$\$

> * \$D(\\mathbf{p}) \> 0\$: Solid rock substrate.  
> * \$D(\\mathbf{p}) \< 0\$: Air / Empty atmosphere.

### **1.1 Volumetric Density Field Construction**

The 3D density field is constructed by perturbing a base planar vertical gradient (derived from the Module 1 & Module 2 heightmaps \$H\_{\\text{eroded}}(x, y)\$) using multi-frequency 3D vector-warped noise functions \$N\_{3\\text{D}}(\\mathbf{p})\$:

\$\$D(\\mathbf{p}) \= H\_{\\text{eroded}}(x, y) \- z \+ \\Omega(x, y, z)\$\$

\$\$\\Omega(\\mathbf{p}) \= \\alpha\_{\\text{cliff}} \\cdot S\\left(\\frac{\\partial H}{\\partial x}, \\frac{\\partial H}{\\partial y}\\right) \\cdot N\_{3\\text{D}}\\left(\\mathbf{p} \+ \\mathbf{W}\_{3\\text{D}}(\\mathbf{p})\\right)\$\$  
Where:

> * \$S(\\nabla H) \= \\text{clamp}\\left(\\frac{\\Vert{}\\nabla H\\Vert{} \- \\theta\_{\\text{flat}}}{\\theta\_{\\text{steep}} \- \\theta\_{\\text{flat}}}, 0.0, 1.0\\right)\$ acts as a **Slope Mask**, restricting volumetric 3D perturbations exclusively to steep cliffs to optimize evaluation overhead and prevent unwanted floating terrain artifacts on flat valley floors.  
> * \$\\mathbf{W}\_{3\\text{D}}(\\mathbf{p}) \= \\left( N\_A(\\mathbf{p}), N\_B(\\mathbf{p}), N\_C(\\mathbf{p}) \\right)\$ is a 3D domain warping vector field creating folded geological strata.

       Air (D \< 0\)  
─────────────────────────  D \= 0 (Isosurface)  
  ▲ Overhang  
  │  ┌───────────┐  
  └──┤ Solid Rock│ (D \> 0\)  
     └───────────┘

### **1.2 Sedimentary Stratification & Differential Erosion**

Sedimentary strata (alternating bands of hard granite/sandstone and soft shale/clay) modulate both density \$D(\\mathbf{p})\$ and local surface normal perturbation. Stratification is modeled as a continuous periodic altitude-based function subjected to geological tilt \$\\mathbf{T}\$:

\$\$\\zeta(\\mathbf{p}) \= z \+ \\mathbf{p} \\cdot \\mathbf{T}\$\$

\$\$S\_{\\text{layer}}(\\mathbf{p}) \= \\sum\_{k=0}^{K-1} A\_k \\cdot \\sin\\left( \\omega\_k \\cdot \\zeta(\\mathbf{p}) \+ \\phi\_k \+ N\_{1\\text{D}}(\\zeta(\\mathbf{p})) \\right)\$\$

#### **Differential Hardness Function**

Local rock hardness \$K\_{\\text{hard}}(\\mathbf{p}) \\in \[0.0, 1.0\]\$ governs erosion resistance and surface displacement depth:

\$\$K\_{\\text{hard}}(\\mathbf{p}) \= \\text{smoothstep}\\left( \-0.2, \\, 0.2, \\, S\_{\\text{layer}}(\\mathbf{p}) \\right)\$\$  
When \$K\_{\\text{hard}}\$ is low (soft rock), the density field is pushed inward (\$\\Delta D \< 0\$), carving structural horizontal undercuts along cliff faces.

### **1.3 Voronoi Structural Jointing & Fracture Fields**

To simulate columnar basalt, granite block jointing, or fractured slate, surface normals \$\\mathbf{N} \= \\frac{\\nabla D}{\\Vert{}\\nabla D\\Vert{}}\$ and local densities are modulated using 3D Cellular/Voronoi metrics.  
Let \$\\mathbf{c}\_i\$ represent the closest Voronoi seed point to \$\\mathbf{p}\$, and \$F\_1, F\_2\$ represent the distances to the first and second nearest seeds respectively:

\$\$\\Delta F(\\mathbf{p}) \= F\_2(\\mathbf{p}) \- F\_1(\\mathbf{p})\$\$  
The fracture jointing profile \$J(\\mathbf{p})\$ isolates sharp cell boundaries:

\$\$J(\\mathbf{p}) \= \\left( 1.0 \- \\text{clamp}\\left( \\frac{\\Delta F(\\mathbf{p})}{w\_{\\text{joint}}}, 0.0, 1.0 \\right) \\right)^p\$\$

> * \$w\_{\\text{joint}}\$: Width of rock fractures / jointing gaps.  
> * \$p\$: Fracture sharpness exponent (\$p \\in \[2.0, 8.0\]\$).

This jointing term modulates displacement along the local surface normal:

\$\$\\mathbf{p}\_{\\text{jointed}} \= \\mathbf{p} \- \\mathbf{N}(\\mathbf{p}) \\cdot J(\\mathbf{p}) \\cdot d\_{\\text{depth}} \\cdot K\_{\\text{hard}}(\\mathbf{p})\$\$

## **2\. Isosurface Extraction: Dual Contouring vs. Marching Cubes**

Module 3 extracts triangle meshes from \$D(\\mathbf{p})\$ using **Dual Contouring** (or Marching Cubes with Gradient Hermite Interpolation) to preserve sharp 90-degree cliff edges and angular fracture planes.

| Extraction Feature | Standard Marching Cubes | Dual Contouring |
| :---- | :---- | :---- |
| **Edge Topology** | Truncates sharp corners (smooths rock edges) | Preserves sharp features via Hermite data |
| **Grid Dual Placement** | Fixed edge intersections | Solves Quadratic Error Function (QEF) inside cell |
| **Adaptive LOD** | Prone to cracks between LOD boundaries | Native octree simplification support |
| **Compute Overhead** | Lower (Table lookup \+ linear interpolation) | Higher (SVD/Eigen solver for QEF per cell) |

### **Quadratic Error Function (QEF) Minimization**

For Dual Contouring, a vertex \$\\mathbf{x}^\*\\\!\$ inside a grid cell containing isosurface edge intersections \$\\mathbf{p}\_i\$ with surface normals \$\\mathbf{n}\_i\$ is placed by minimizing \$E(\\mathbf{x})\$:

\$\$E(\\mathbf{x}) \= \\sum\_{i} \\left( \\mathbf{n}\_i \\cdot (\\mathbf{x} \- \\mathbf{p}\_i) \\right)^2\$\$

\$\$\\mathbf{x}^\* \= \\arg\\min\_{\\mathbf{x}} E(\\mathbf{x}) \\implies \\mathbf{A} \\mathbf{x} \= \\mathbf{b}\$\$

\$\$\\mathbf{A} \= \\sum\_i \\mathbf{n}\_i \\mathbf{n}\_i^T, \\quad \\mathbf{b} \= \\sum\_i (\\mathbf{n}\_i \\cdot \\mathbf{p}\_i) \\mathbf{n}\_i\$\$

## **3\. Production GLSL Compute Shader Implementation**

This compute shader evaluates 3D density fields, sedimentary layers, and Voronoi jointing over a 3D voxel grid volume, writing output density values and analytic surface gradients (\$\\nabla D\$) into a 3D volume texture.

OpenGL Shading Language  
\#version 450 core

layout(local\_size\_x \= 8, local\_size\_y \= 8, local\_size\_z \= 8\) in;

// \----------------------------------------------------------------------------  
// BINDINGS & UNIFORMS  
// \----------------------------------------------------------------------------  
layout(r32f, binding \= 0\) uniform image3D u\_DensityVolume;  
layout(rgba16f, binding \= 1\) uniform image3D u\_GradientAndHardnessVolume;  
layout(binding \= 2\) uniform sampler2D u\_ErodedHeightmap; // Module 1 \+ 2 Base

layout(push\_constant) uniform VolumetricParams {  
    vec3 u\_VolumeOrigin;       // World position origin of this voxel chunk  
    float u\_VoxelSize;         // Size of single voxel in meters (e.g., 0.5m)  
    int u\_VolumeResolution;    // Voxel grid resolution (e.g., 64x64x64)  
    float u\_StrataFrequency;   // Frequency of sedimentary layering (0.1 to 0.5)  
    float u\_JointScale;        // Voronoi fracture scale (0.05 to 0.2)  
    float u\_OverhangStrength;  // 3D displacement amplitude (2.0 to 15.0m)  
} params;

// \----------------------------------------------------------------------------  
// 3D SIMPLEX NOISE & HASHING  
// \----------------------------------------------------------------------------  
vec3 hash33(vec3 p) {  
    p \= vec3(dot(p, vec3(127.1, 311.7, 74.7)),  
             dot(p, vec3(269.5, 183.3, 246.1)),  
             dot(p, vec3(113.5, 271.9, 124.6)));  
    return \-1.0 \+ 2.0 \* fract(sin(p) \* 43758.5453123);  
}

float simplexNoise3D(vec3 p) {  
    const float K1 \= 0.333333333;  
    const float K2 \= 0.166666667;

    vec3 i \= floor(p \+ (p.x \+ p.y \+ p.z) \* K1);  
    vec3 a \= p \- i \+ (i.x \+ i.y \+ i.z) \* K2;

    vec3 g \= step(a.yzx, a.xyz);  
    vec3 l \= 1.0 \- g;  
    vec3 i1 \= min(g.xyz, l.zxy);  
    vec3 i2 \= max(g.xyz, l.zxy);

    vec3 b \= a \- i1 \+ K2;  
    vec3 c \= a \- i2 \+ 2.0 \* K2;  
    vec3 d \= a \- 1.0 \+ 3.0 \* K2;

    vec4 h \= max(0.6 \- vec4(dot(a, a), dot(b, b), dot(c, c), dot(d, d)), 0.0);  
    vec4 n \= h \* h \* h \* h \* vec4(  
        dot(a, hash33(i)),  
        dot(b, hash33(i \+ i1)),  
        dot(c, hash33(i \+ i2)),  
        dot(d, hash33(i \+ 1.0))  
    );

    return dot(n, vec4(32.0));  
}

// \----------------------------------------------------------------------------  
// VORONOI 3D FRACTURE FIELD  
// \----------------------------------------------------------------------------  
float calculateVoronoiJointing(vec3 p) {  
    vec3 i \= floor(p);  
    vec3 f \= fract(p);

    float f1 \= 8.0;  
    float f2 \= 8.0;

    for (int z \= \-1; z \<= 1; \++z) {  
        for (int y \= \-1; y \<= 1; \++y) {  
            for (int x \= \-1; x \<= 1; \++x) {  
                vec3 g \= vec3(float(x), float(y), float(z));  
                vec3 o \= hash33(i \+ g) \* 0.5 \+ 0.5;  
                vec3 r \= g \+ o \- f;  
                float d \= dot(r, r);

                if (d \< f1) {  
                    f2 \= f1;  
                    f1 \= d;  
                } else if (d \< f2) {  
                    f2 \= d;  
                }  
            }  
        }  
    }

    f1 \= sqrt(f1);  
    f2 \= sqrt(f2);  
    float diff \= f2 \- f1;  
    return pow(1.0 \- clamp(diff \* 4.0, 0.0, 1.0), 4.0); // Joint line intensity  
}

// \----------------------------------------------------------------------------  
// CORE DENSITY EVALUATION  
// \----------------------------------------------------------------------------  
float EvaluateDensityAndRockData(vec3 worldPos, out float outHardness) {  
    // 1\. Fetch Module 1 & 2 Base Height map  
    vec2 uv \= worldPos.xy \* 0.0001; // Scale to height map bounds  
    float baseHeight \= texture(u\_ErodedHeightmap, uv).r;

    // Calculate local slope from heightmap derivatives  
    vec2 eps \= vec2(0.0005, 0.0);  
    float hR \= texture(u\_ErodedHeightmap, uv \+ eps.xy).r;  
    float hT \= texture(u\_ErodedHeightmap, uv \+ eps.yx).r;  
    float slope \= length(vec2(hR \- baseHeight, hT \- baseHeight)) \* 100.0;  
    float slopeMask \= smoothstep(0.4, 1.2, slope); // Restrict 3D overhangs to cliffs

    // 2\. Sedimentary Layering & Differential Hardness  
    float tilt \= worldPos.x \* 0.05 \+ worldPos.y \* 0.02; // Tilted strata  
    float strataPhase \= (worldPos.z \+ tilt) \* params.u\_StrataFrequency;  
    float strataPattern \= sin(strataPhase \+ simplexNoise3D(worldPos \* 0.02) \* 2.0);  
    outHardness \= smoothstep(-0.3, 0.3, strataPattern);

    // Hard layers protrude (+D), soft layers undercut (-D)  
    float strataDisplacement \= (outHardness \- 0.5) \* 1.5;

    // 3\. 3D Domain Warped Overhang Noise  
    vec3 warp \= vec3(  
        simplexNoise3D(worldPos \* 0.03),  
        simplexNoise3D(worldPos \* 0.03 \+ vec3(5.2, 1.3, 0.8)),  
        simplexNoise3D(worldPos \* 0.03 \+ vec3(1.7, 9.2, 3.4))  
    );  
    float overhangNoise \= simplexNoise3D((worldPos \+ warp \* 5.0) \* 0.015);

    // 4\. Voronoi Fracture Jointing  
    float jointing \= calculateVoronoiJointing(worldPos \* params.u\_JointScale);  
    float fractureDisplacement \= \-jointing \* (1.2 \- outHardness) \* 0.8;

    // 5\. Combine into Final Scalar Density Field  
    float total3DOffset \= (overhangNoise \* params.u\_OverhangStrength \+ strataDisplacement \+ fractureDisplacement) \* slopeMask;  
      
    // Solid below surface, air above  
    float density \= (baseHeight \+ total3DOffset) \- worldPos.z;

    return density;  
}

// \----------------------------------------------------------------------------  
// MAIN EXECUTION  
// \----------------------------------------------------------------------------  
void main() {  
    ivec3 id \= ivec3(gl\_GlobalInvocationID);  
    if (id.x \>= params.u\_VolumeResolution ||   
        id.y \>= params.u\_VolumeResolution ||   
        id.z \>= params.u\_VolumeResolution) {  
        return;  
    }

    vec3 worldPos \= params.u\_VolumeOrigin \+ vec3(id) \* params.u\_VoxelSize;

    // Evaluate Density & Rock Properties  
    float hardness;  
    float density \= EvaluateDensityAndRockData(worldPos, hardness);

    // Compute Analytic Gradient Vector (Central Differences for Surface Normal)  
    float delta \= params.u\_VoxelSize \* 0.5;  
    float dummy;  
    float dX1 \= EvaluateDensityAndRockData(worldPos \+ vec3(delta, 0.0, 0.0), dummy);  
    float dX2 \= EvaluateDensityAndRockData(worldPos \- vec3(delta, 0.0, 0.0), dummy);  
    float dY1 \= EvaluateDensityAndRockData(worldPos \+ vec3(0.0, delta, 0.0), dummy);  
    float dY2 \= EvaluateDensityAndRockData(worldPos \- vec3(0.0, delta, 0.0), dummy);  
    float dZ1 \= EvaluateDensityAndRockData(worldPos \+ vec3(0.0, 0.0, delta), dummy);  
    float dZ2 \= EvaluateDensityAndRockData(worldPos \- vec3(0.0, 0.0, delta), dummy);

    vec3 gradient \= normalize(vec3(dX2 \- dX1, dY2 \- dY1, dZ2 \- dZ1));

    // Store in 3D Volume Textures  
    imageStore(u\_DensityVolume, id, vec4(density, 0.0, 0.0, 0.0));  
    imageStore(u\_GradientAndHardnessVolume, id, vec4(gradient, hardness));  
}

## **4\. Parameter Specification Table**

| Parameter Name | Symbol | Range / Units | Recommended Default | Physical Effect / Description |
| :---- | :---- | :---- | :---- | :---- |
| **Strata Frequency** | \$\\omega\_k\$ | \$0.05 \- 0.5\$ \$\\text{m}^{-1}\$ | \$0.15\$ \$\\text{m}^{-1}\$ | Spatial frequency of sedimentary layers along \$Z\$-axis. |
| **Jointing Scale** | \- | \$0.02 \- 0.25\$ \$\\text{m}^{-1}\$ | \$0.08\$ \$\\text{m}^{-1}\$ | Controls average size of fractured rock blocks / columns. |
| **3D Overhang Amplitude** | \$\\alpha\_{\\text{cliff}}\$ | \$1.0 \- 20.0\$ \$\\text{m}\$ | \$6.0\$ \$\\text{m}\$ | Maximum horizontal undercut depth for cliff overhangs/caves. |
| **Slope Mask Threshold** | \$\\theta\_{\\text{flat}}, \\theta\_{\\text{steep}}\$ | \$0.2 \- 1.5\$ (Slope) | \$\[0.4, 1.2\]\$ | Slope bounds determining where 2D heightmap transitions to 3D density evaluation. |
| **Fracture Depth** | \$d\_{\\text{depth}}\$ | \$0.2 \- 2.0\$ \$\\text{m}\$ | \$0.6\$ \$\\text{m}\$ | Recesses joint lines inward along surface normals. |
| **Strata Tilt Vector** | \$\\mathbf{T}\$ | \$0.0 \- 0.2\$ (Rad) | \$(0.05, 0.02)\$ | Tilts bedding planes to simulate tectonic uplift angles. |
