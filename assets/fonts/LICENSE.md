# Roboto

`Roboto-Regular.ttf` is the Roboto typeface by Google.

- License: Apache License 2.0 — https://www.apache.org/licenses/LICENSE-2.0
- Upstream: https://github.com/googlefonts/roboto-2

Bundled so the mobile UI has a proportional interface typeface instead of the
monospace default (FiraMono) that Bevy compiles in for `default_font`.
